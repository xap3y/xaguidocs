---
title: Custom paginator
description: Customize automatic previous and next page controls.
---

```java
GuiMenu menu = xaGui.createMenu("&8Pages", 3, 3);

menu.addPaginator();
menu.setPreviousPageButton(new GuiButton(Material.ARROW)
        .setName("&ePrevious")
        .setLore("&7Go back one page")
        .getItem());
menu.setNextPageButton(new GuiButton(Material.ARROW)
        .setName("&eNext")
        .setLore("&7Go forward one page")
        .getItem());

menu.setPageSwitchSound(Sound.ITEM_BOOK_PAGE_TURN);
menu.fillBorder();
menu.addCloseButtonAllPages();

menu.setSlot(0, 13, Material.DIAMOND);
menu.setSlot(1, 13, Material.EMERALD);
menu.setSlot(2, 13, Material.GOLD_INGOT);

menu.setOnPageSwitch(data -> data.getPlayer().sendMessage(
        "Now viewing page " + (data.getTargetPage() + 1)));

menu.open(player);
```

Use `XaGui.setPreviousPageButton(...)` and `setNextPageButton(...)` during startup to change defaults for every menu.
